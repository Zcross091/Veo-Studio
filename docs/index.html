Developer Integration in Seconds

Call the API from cURL, Python, or Node.js with your newly issued key.

# Generate a 16:9 cinematic video via Auto-Cascade

  -H "Authorization: Bearer YOUR_VEO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Cyberpunk city at midnight with neon rain",
    "provider": "auto",
    "aspect": "16:9",
    "duration": 5
  }'
